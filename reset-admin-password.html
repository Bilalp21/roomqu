🔑 Reset Admin Password

⚠️ Perhatian: User admin@roomqu.id sudah ada di Firebase, tapi passwordnya berbeda dari yang Anda coba.
ℹ️ Solusi: Gunakan salah satu metode berikut untuk reset password:

Metode 1: Reset Password via Email (Recommended)

  1. Klik tombol "Send Password Reset Email" di bawah
  2. Cek inbox email admin@roomqu.id
  3. Klik link reset password di email
  4. Set password baru menjadi 123456
  5. Login ke /admin/login

Metode 2: Hapus & Buat Ulang (Via Firebase Console)

  1. Buka Firebase Console
  2. Cari user admin@roomqu.id
  3. Hapus user tersebut
  4. Kembali ke /create-admin.html
  5. Buat user baru dengan password 123456
